# Data Dictionary - Emotions NLP v2

This document describes the columns/features included in the `emotions-nlp-v2` dataset.

| Column | Type | Description |
| :--- | :--- | :--- |
| `text` | `string` | The raw input text. Length ranges from 10 to 500 characters. |
| `joy` | `int` | Binary label (1 if the text expresses joy, 0 otherwise). |
| `sadness` | `int` | Binary label (1 if the text expresses sadness, 0 otherwise). |
| `anger` | `int` | Binary label (1 if the text expresses anger, 0 otherwise). |
| `fear` | `int` | Binary label (1 if the text expresses fear, 0 otherwise). |
| `surprise` | `int` | Binary label (1 if the text expresses surprise, 0 otherwise). |
| `neutral` | `int` | Binary label (1 if the text expresses no specific emotion, 0 otherwise). |
